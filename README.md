# Antigravity Monitor（反重力监控）

面向 Windows 10 / 11 的轻量本地只读桌面监控与命令行遥测工具，用于实时观测 Antigravity 2.x 的**服务端缓存命中率、请求体大小变化轨迹、真实响应速度（TTFT 与 tok/s）、大上下文保鲜倒计时、近 24 小时滚动步数保护线、分池配额与重置时间，以及底层 `language_server.log` 滑动窗口异常**。

## 核心特点

- **纯只读、零侵入、并发安全**：不修改 Antigravity 快捷方式或第三方切换工具启动参数，不开 CDP 调试端口，不拦截网络流量，不上传任何账号凭据；命令行模式默认严格零写盘，多对话并发调用无文件锁竞态。
- **四色防误报缓存引擎与直白冷启短标**：逐轮解析 `transcript.jsonl`，精准区分四类状态并分别着色：
  - **绿（缓存命中）**：正常热缓存命中；
  - **紫（压缩重热）**：结合 `CHECKPOINT` 事件与上下文体量真实缩水判定，压缩耗时长也不误报，正文提及压缩关键词也不会触发假阳性；
  - **橙（正常冷启）**：首轮、闲置超时自然重热、切号首拍、切模型、全局规则（`GEMINI.md`）修改、小上下文（`<32K`）及首次跨过 32K 门槛——主面板与顶栏对正常冷启 `0.0%` 直接展示清晰中文短标（`<32K` / `首建缓` / `切号冷` / `切模冷` / `压缩冷` / `回溯冷` / `规则冷`），避免与掉缓存混淆；
  - **红（异常掉缓存）**：同模型短间隔内异常归零（`abnormal_zero`）或真实前缀严重部分失效（`partial_miss`，已排除大工具输出引起的正常稀释 `cached_diluted`），连续 `>= 3` 步异常掉缓存或近 10 步高频异常（`>= 4` 次且 `< 50%`）升红灯 `T1`（连续 `2` 步归橙色 `WARN` 高留意观察），防单步偶中「洗白」且支持按切号账本隔离历史账号红条；对已连续恢复或停聊老化的旧异常预警自动销账，并在主对话全绿时对后台子代理偶发单步瞬抖降噪（绝不放松真实连掉与高频 `T1` 判定）；
  - **同窗口换号过渡入口**：切号后若某活跃主对话在当前号尚未发出新步，主面板会置顶柔和过渡入口（标记 `待首步`，零污染评级与统计），方便一键点开查看跨账号完整长线与换号竖线。
- **主对话 / 子代理分类与多主对话并行**：自动识别主对话与子代理（`主对话 / 子代理 / 全部` 切换，内置主对话保护槽位防止大批子代理挤爆列表）；支持 24 条活跃对话滚动与底边自由拉高（`3～12` 行）；支持右键或详情页 **📌 聚焦指定主对话**到主面板，大上下文保鲜卡悬停可一览全部活跃大上下文主对话倒计时。
- **单对话长线体检弹窗（后台异步零阻塞 + 千步像素聚合 + 模型/换号色带）**：左键点击任意对话行即可 `<50ms` 瞬间打开无边框长线详情窗口（后台线程加载不卡主界面），随主面板 2.5s 轮询**实时动态刷新**新步与保鲜倒计时（随主窗收起或隐藏自动同步关闭）；支持 `近 60 步 / 近 180 步 / 仅异常 / 全部步数` 4 档筛选、千步长对话智能像素聚合（保留最差延迟峰与异常色、图元受控不混叠）、左键点击锁定单步与 `←/→` 键盘逐拍精调、双行读数条拆解 `缓存命中 / 新输入 / 输出`、**顶部彩色模型时间色带与跨号 `换号` 蓝虚线**（全覆盖 `MODEL_PLACEHOLDER_M*` 含 Opus/Sonnet 5.5 枚举）、多模态附件载荷标注（`图N(X.XM)`）及四色缓存长线。
- **分模型测速基线、保鲜抢救窗与日志明细透视**：按模型族（Carbon / Neon / Hydrogen+Flash / 3P）自动匹配差异化 TTFT/TPS 速度基线与 T2 恢复门槛（全上下文生效，排除短输出伪极速误豁免），并在空模型切模时基于 SQLite 真实模型元数据自动纠正误报；大上下文保鲜按模型区分安全保鲜窗（Carbon 180s / Neon 240s）与 `0～-90s` 临界抢救窗，高体量临界对话优先置顶提醒；主面板显露真实订阅档位（`Ultra / Pro / Free`）、Gemini 与 3P 双分池配额、重置倒计时与实时消耗速率/预计耗尽预警；底层日志四格（`503 繁忙 / 请求超时 / 403 权限 / 网络重试`）支持悬停查看分类时间线与出事对话摘要、左键一键复制，并保持按账号隔离、多图上传超时自动分流与跨接口代理断流去重识别。
- **新一代近 24 小时滚动步数保护线（时间衰减 + 同档位弱先验 + 配额联动）**：顶栏胶囊、托盘提示与主进度条统一采用「近 24 小时滚动步数保护线」（主数字保持直观原始步数，悬停以通俗中文展开依据）；基于 `3.5 天` 半衰期时间衰减加权、同订阅档位（严格按 `userTier.id` 区分 Ultra / Pro / Free，绝不跨档混算）兄弟号弱先验、单对话偶发漂移与全号限流分级惩罚、跨午夜连续恢复平滑过渡（杜绝断崖跳变且绝不盲目追高），并联动实时 5h/周额余量与消耗斜率估算剩余可跑步数；内置轻量「⚙ 参数设置」弹窗支持透明度实时预览、采样频率、保鲜与测速基线、槽位清理与更新方式热重载，配置文件采用增量合并保存杜绝覆盖手改 JSON。
- **本机 500 会话槽位水位监控与安全子代理让位清理（盘点提速 10×）**：活跃目录启用短 TTL 缓存与精准单会话失效，二次盘点 `<300ms`；点击主面板槽位条可展开「本机 500 槽位分布」详情窗，支持按时间/体积/步数排序与关键词搜索，自动区分文件锁定与回收站不可用；支持一键手动清理 2 小时外已结束子代理并默认开启安全自动让位清理（6 重防误删护栏 + 30 分钟硬下限绝不突破）。
- **全用户默认后台下载更新、三档可调与失败提醒**：启动 8 秒后在后台低频检查 GitHub 远端 `version.json`（默认每 30 分钟，零阻塞热路径）；**默认采用「后台下载（下次启动自动生效）」策略**——发现新版本后自动静默校验并原子更新（不打断当前使用，面板浮出青蓝提示条并给出一键「立即重启」），也可在更新条、右键菜单或托盘「更新方式」中随时切换为 **「自动下载并立即重启」** 或 **「仅提示（手动点击更新）」**；同时支持 **Git 克隆用户（严格干净工作区 `--ff-only` 快进）** 与 **直接下载 ZIP 压缩包/未装 Git 用户（官方 ZIP 校验 + 自动备份回滚 + 原子替换，绝不覆盖 `config.json` 与 `account_ledger.json`）**；若遇到目录权限不足（如受 UAC 保护的 `Program Files`）、断网或校验异常会自动回滚并强制弹出醒目横幅与系统托盘提醒。
- **跨账号 TTFT 连续衔接与完整单对话详情窗**：当同一对话先后跨越多个账号时，主面板通过缓存化的全局对齐投影自动找回该账号更早在此对话的真实 TTFT 柱子；右侧单对话长线详情窗永远展示该对话自身完整轨迹，不被左侧账号筛选切碎。
- **面向自动化的无阻塞 CLI & `--json` 契约**：提供无 `pause` 包装入口 `agy-watch.cmd`，支持 `--json`、`--cli`、`--readonly`、`--conversation-id <id>`、`--account`、`--range` 及显式 `--clean-subagents [--dry-run] [--min-age]`，详见 [CLI 调用说明](docs/CLI调用说明.md)。

## 健康评级与压力说明

| 评级 | 灯号 | 综合压力 (`pressure`) | CLI 退出码 | 判定条件 |
|---|---|---|---|---|
| **IDLE 离线** | 青/灰 | `offline_unknown` | `2` | 客户端未运行且无近 2 分钟实时轨迹，暂停实时异常告警 |
| **T0 健康** | 绿灯 | `normal`（超步数线时为 `warn`/`red`） | `0`（超步数线为 `1`） | 近 30 分钟缓存、TTFT 与底层日志均健康（近 24 小时滚动步数超黄/红线仅作独立保护提醒，不覆盖真实 T0/T1/T2 评级） |
| **留意预警** | 橙灯 | `warn` | `1` | 未恢复/未老化的异常掉缓存预警（含连续 `2` 步异常掉缓存高留意观察；连续命中恢复或停聊老化后自动销账，主对话全绿时后台子代理偶发单步瞬抖自动降噪）、偶发 1 次 503 或 1 次流超时，或疑似暗限速 |
| **T1 掉缓存** | 红灯 | `degraded` | `1` | 活跃会话连续 `>= 3` 步异常掉缓存（`abnormal_zero` / `partial_miss`），或近 10 步异常 `>= 4` 次且命中率 `< 50%` |
| **T2 限流黑洞** | 红灯 | `degraded` | `1` | 近 30 分钟累计 `503 + 流超时 >= 2` 次且主对话模型事后未稳定恢复 |
| **T3 封禁告警** | 红灯 | `degraded` | `1` | 近 30 分钟检测到 `403 TOS_VIOLATION / PERMISSION_DENIED` |

## 数据源说明（全部本地只读）

| 数据源 | 本地路径 | 用途 |
|---|---|---|
| 对话轨迹日志 | `%USERPROFILE%\.gemini\antigravity\brain\<id>\.system_generated\logs\transcript.jsonl` | 逐轮 `input_tokens`、`cache_read_tokens`、请求体增量 `±ΔK`、`CHECKPOINT` 压缩与 `Undo` 回溯事件、`ERROR_MESSAGE` 报错反查 |
| 对话元数据库 | `%USERPROFILE%\.gemini\antigravity\conversations\<id>.db`（`mode=ro`） | `TTFT`、`streaming`、`tok/s`、`maxContextTokens` 与单对话全量长线速度曲线 |
| 会话摘要索引库 | `%USERPROFILE%\.gemini\antigravity\conversation_summaries.db`（`mode=ro`） | 500 槽位主对话 / 子代理分类识别与 6 重防误删校验 |
| 语言服务日志 | `%APPDATA%\Antigravity\logs\language_server.log` | 增量捕获 `503 No capacity`、动态时长流超时、`403 封禁` 与代理断连重试 |
| 本地在线 Hub | `%USERPROFILE%\.gemini\antigravity\daemon\hub_*.json`（`127.0.0.1`） | 只读 `GetUserStatus` 与 `RetrieveUserQuotaSummary` 实时获取脱敏账号、套餐档位及 `gemini` / `3p` 分池 5h + 周额度与原生 `resetTime` |
| 全局规则修改时间 | `%USERPROFILE%\.gemini\GEMINI.md`（仅只读 `stat()` 时间戳） | 识别全局规则更新触发的正常前缀冷启（`规则冷`），不读取或上传任何规则正文 |
| Cockpit 历史库（可选降级） | `%USERPROFILE%\.antigravity_cockpit\platform-quota-history-v1.sqlite` | 仅当旧版客户端未提供 `RetrieveUserQuotaSummary` 时，严格同邮箱只读补全分池周额度与 `reset_at`；未安装或离线时自动跳过 |

## 快速开始

### 1. 安装依赖（Windows 10 / 11，推荐 Python 3.10–3.14）

```powershell
pip install -r requirements.txt
```

### 2. 桌面监控启动与日常交互

- **无黑框启动**：双击 `启动反重力监控.vbs`（优先自动检测 `.venv` / `venv` 及本机 Python 3.10–3.14）
- **交互手势**：
  - 拖拽顶部胶囊移动位置并自动记忆坐标；轻点顶部胶囊展开/收起详情；
  - 鼠标悬停活跃对话行查看近 10 步逐拍请求体大小、净变化 `±ΔK`、TTFT 与缓存原因；
  - **左键点击任意活跃对话行**打开「单对话长线详情窗口」查看完整增长/TTFT/缓存三曲线；
  - **右键任意活跃对话行**快速查看详情或 **📌 聚焦该对话**到主面板吞吐与保鲜卡；
  - 拖拽窗口底部细灰条自由调节列表显示行数（`3～12` 行），滚动条与滚轮浏览最多 24 条对话；
  - 点击右上角 `主题:星蓝 ⇄` 实时切换「午夜星蓝 / 深炭极简」双主题。

### 3. 命令行与多代理自动化调用

详细 JSON 字段契约、退出码与并发只读边界见 [docs/CLI调用说明.md](docs/CLI调用说明.md)：

```powershell
# 无阻塞 JSON 结构化体检（默认严格零写盘，返回语义退出码 0/1/2）
.\agy-watch.cmd --json

# 定向附带指定对话详情
.\agy-watch.cmd --json --conversation-id <conversation-id-or-prefix>

# 脱敏文字摘要
.\agy-watch.cmd --cli
```

### 4. 桌面快捷方式、开机自启与测试

```powershell
# 创建桌面快捷方式并启用 Startup 文件夹开机自启（零写注册表）
python scripts/install_shortcuts.py --enable-startup

# 卸载桌面快捷方式并取消开机自启
python scripts/install_shortcuts.py --disable-startup --remove-desktop

# 运行全部单元测试
python -m unittest discover -s tests -v
```
